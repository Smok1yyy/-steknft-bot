# StekNft-style starter: бот + Mini App

Это стартовый проект, а не готовая копия закрытого сервиса. Он включает:
- Telegram-бот с `/start` и кнопкой открытия Mini App;
- тёмный интерфейс с вкладками «Чаты», «Оффер», «Настройки»;
- проверку подписи `initData` Telegram на сервере;
- сохранение настроек и черновиков в SQLite;
- создание черновика оффера без заявления, что сделка реально отправлена.

## 1. Создай бота
1. Открой `@BotFather` в Telegram и выполни `/newbot`.
2. Скопируй токен нового бота.
3. Не отправляй токен никому и не вставляй его в публичный код.

## 2. Размещение бесплатно
Можно попробовать Render Free:
1. Загрузи папку проекта в свой GitHub-репозиторий.
2. В Render создай Web Service из этого репозитория.
3. В переменных окружения задай `BOT_TOKEN` и `APP_URL`.
4. Сначала можно временно указать URL сервиса как `APP_URL`, например `https://имя-сервиса.onrender.com`.
5. После деплоя открой `https://имя-сервиса.onrender.com/api/health` — ожидается `{"ok":true,...}`.
6. Укажи в BotFather домен Mini App через настройки бота, если Telegram этого попросит.

**Важно:** бесплатные хостинги могут усыплять сервис, иметь ограничения и не гарантировать круглосуточную работу. Для проверки Mini App используй HTTPS. SQLite на эфемерном бесплатном диске может потерять данные при пересоздании сервиса — перед серьёзным использованием нужна постоянная база данных.

## 3. Локальный запуск
Требуется Python 3.11+:
```bash
pip install -r requirements.txt
```
Linux/macOS:
```bash
export BOT_TOKEN="ТОКЕН_ОТ_BOTFATHER"
export APP_URL="https://твой-публичный-https-адрес"
python main.py
```
На Android через Pydroid 3 установи зависимости и задай переменные окружения способом, доступным в твоей среде. Для Mini App нужен публичный HTTPS-адрес; локальный запуск сам по себе его не создаёт.

## 4. Что пока не подключено
- фактическая отправка/принятие NFT-офферов;
- реальная проверка владения подарком, цены и доступности сделки;
- авторизация личного Telegram-аккаунта через MTProto.
Не добавляй в проект пароль или код входа от своего Telegram. Для следующего этапа сначала нужно проверить поддерживаемые официальные методы и разрешённую модель авторизации.
